# Synthetic compatibility fixture

`synthetic-benchmark.json` was generated by the unmodified Anthropic skill-creator aggregator at commit `dbd4588f9e1033efb41dad4bef2f7947c8993d44` from handwritten grading/timing files. It contains no model experiment. See `scripts/create-impact-fixture.mjs` for fixture construction.

The source metadata intentionally retains the upstream template placeholders so the report can flag incomplete provenance. Token values from summary-only imports are withheld: upstream fields can fall back to character counts. Use raw `timing.json` to resolve exact counters when available.

```sh
node skills/skill-impact/scripts/report.mjs --input examples/impact/synthetic-benchmark.json --out outputs/example-impact --data-kind synthetic
node skills/skill-impact/scripts/gate.mjs --evidence outputs/example-impact/evidence.json --allow-synthetic --markdown outputs/example-impact/pr-summary.md
```

`--allow-synthetic` is only for offline demonstration/tests. Without it, a synthetic report cannot pass the regression gate. The report and gate do not establish model effectiveness or program eligibility.
