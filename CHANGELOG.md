# Changelog

## 0.1.0-alpha.1

Initial public-source alpha:

- Offline reporting for documented Anthropic-compatible benchmark and ctx-eval artifacts.
- Paired metric coverage, exploratory task-clustered quality intervals, source hashes, and integrity notes.
- HTML, SVG, CSV, LaTeX, evidence JSON and PR-ready Markdown output.
- Configurable regression policy and a standalone reporting Skill.
- Synthetic compatibility examples and offline CI configuration.
- Experimental coding-agent runner and prompt/instruction-file tooling.

No model-performance improvement, external adoption, or end-to-end live-agent validation is claimed by this release.
